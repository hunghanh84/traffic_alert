# BẢNG KỊCH BẢN USE CASES - NGƯỜI DÙNG

## 1. ĐĂNG NHẬP

| Use case name        | Đăng nhập                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Description**      | Người dùng đăng nhập để sử dụng các tính năng của hệ thống                                                                                                                                                                                                                                                                                                                                                                    |
| **Actors**           | Người dùng đã đăng ký tài khoản, Admin                                                                                                                                                                                                                                                                                                                                                                                        |
| **Input**            | Email, mật khẩu                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Output**           | Thông báo "Đăng nhập thành công"                                                                                                                                                                                                                                                                                                                                                                                              |
| **Basic Flow**       | 1. Người dùng chọn "Đăng nhập"<br>2. Người dùng nhập email và mật khẩu<br>3. Người dùng nhấn nút "Đăng nhập"<br>4. Hệ thống kiểm tra thông tin<br>5. Hệ thống hiển thị thông báo "Đăng nhập thành công"<br>6. Hệ thống chuyển hướng: User → Trang chủ, Admin → Dashboard<br>=> Kết thúc use case                                                                                                                              |
| **Alternative Flow** | **2a.** Người dùng nhập thông tin theo thứ tự bất kỳ miễn đầy đủ trước khi nhấn "Đăng nhập"<br>**1a.** Người dùng click "Đăng ký ngay" => Chuyển sang use case "Đăng ký"<br>**3a.** Người dùng click "Quên mật khẩu?" => Chuyển sang use case "Quên mật khẩu"                                                                                                                                                                 |
| **Exception Flow**   | **2a.** Người dùng thoát website => Kết thúc use case<br>**2b.** Email sai định dạng => Hiển thị lỗi "Email không đúng định dạng"<br>**4a.** Email hoặc mật khẩu sai => Hiển thị lỗi "Email hoặc mật khẩu không chính xác"<br>**4b.** Email chưa xác thực => Hiển thị lỗi "Vui lòng xác thực email" + Nút "Gửi lại mã"<br>**4c.** Tài khoản bị vô hiệu hóa => Hiển thị lỗi "Tài khoản đã bị vô hiệu hóa" => Kết thúc use case |

## 2. ĐĂNG KÝ TÀI KHOẢN

| Use case name        | Đăng ký tài khoản                                                                                                                                                                                                                                                                                                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Description**      | Khách vãng lai đăng ký tài khoản mới để sử dụng hệ thống                                                                                                                                                                                                                                                                                                                     |
| **Actors**           | Khách vãng lai                                                                                                                                                                                                                                                                                                                                                               |
| **Input**            | Tên đăng nhập, email, mật khẩu, số điện thoại, phường/xã                                                                                                                                                                                                                                                                                                                     |
| **Output**           | Thông báo "Đăng ký thành công. Vui lòng kiểm tra email"                                                                                                                                                                                                                                                                                                                      |
| **Basic Flow**       | 1. Khách vãng lai chọn "Đăng ký"<br>2. Khách vãng lai nhập thông tin đăng ký<br>3. Khách vãng lai nhấn nút "Đăng ký"<br>4. Hệ thống kiểm tra và lưu tài khoản<br>5. Hệ thống gửi mã OTP qua email<br>6. Chuyển sang trang xác thực email<br>=> Kết thúc use case                                                                                                             |
| **Alternative Flow** | **2a.** Khách vãng lai nhập thông tin theo thứ tự bất kỳ miễn đầy đủ<br>**3a.** Khách vãng lai nhấn "Hủy" => Kết thúc use case<br>**1a.** Khách vãng lai click "Đăng nhập ngay" => Chuyển sang use case "Đăng nhập"                                                                                                                                                          |
| **Exception Flow**   | **2a.** Khách vãng lai thoát trang => Kết thúc use case<br>**2b.** Email sai định dạng => Hiển thị lỗi "Email không đúng định dạng"<br>**2c.** Mật khẩu < 8 ký tự => Hiển thị lỗi "Mật khẩu phải có ít nhất 8 ký tự"<br>**4a.** Email đã tồn tại => Hiển thị lỗi "Email đã được sử dụng"<br>**4b.** Tên đăng nhập đã tồn tại => Hiển thị lỗi "Tên đăng nhập đã được sử dụng" |

## 3. CẬP NHẬT THÔNG TIN CÁ NHÂN

| Use case name        | Cập nhật thông tin cá nhân                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Description**      | Người dùng cập nhật thông tin cá nhân của mình trong hệ thống                                                                                                                                                                                                                                                                                                                                     |
| **Actors**           | Người dùng đã đăng nhập                                                                                                                                                                                                                                                                                                                                                                           |
| **Input**            | Tên đăng nhập, số điện thoại, email, phường/xã, khu vực                                                                                                                                                                                                                                                                                                                                           |
| **Output**           | Thông báo "Cập nhật thông tin thành công"                                                                                                                                                                                                                                                                                                                                                         |
| **Basic Flow**       | 1. Người dùng chọn "Tài khoản"<br>2. Hệ thống hiển thị form với thông tin hiện tại<br>3. Người dùng chỉnh sửa các thông tin muốn thay đổi<br>4. Người dùng nhấn nút "Cập nhật"<br>5. Hệ thống kiểm tra dữ liệu hợp lệ<br>6. Hệ thống lưu thông tin mới vào database<br>7. Hệ thống hiển thị thông báo "Cập nhật thông tin thành công"<br>=> Kết thúc use case                                     |
| **Alternative Flow** | **3a.** Người dùng chỉ sửa một số trường, các trường khác giữ nguyên<br>**4a.** Người dùng nhấn "Hủy" => Quay lại trang trước, không lưu thay đổi => Kết thúc use case                                                                                                                                                                                                                            |
| **Exception Flow**   | **3a.** Người dùng thoát trang => Không lưu thay đổi => Kết thúc use case<br>**3b.** Số điện thoại sai định dạng => Hiển thị lỗi "Số điện thoại không hợp lệ"<br>**3c.** Email sai định dạng => Hiển thị lỗi "Email không đúng định dạng"<br>**5a.** Email đã tồn tại => Hiển thị lỗi "Email đã được sử dụng"<br>**5b.** Tên đăng nhập đã tồn tại => Hiển thị lỗi "Tên đăng nhập đã được sử dụng" |

## 4. LỌC VÀ TÌM KIẾM CẢNH BÁO

| Use case name        | Lọc và tìm kiếm cảnh báo                                                                                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Description**      | Người dùng lọc và tìm kiếm cảnh báo theo các tiêu chí                                                                                                                                                                    |
| **Actors**           | Người dùng đã đăng nhập                                                                                                                                                                                                  |
| **Input**            | Từ khóa, loại cảnh báo, mức độ, vị trí, thời gian                                                                                                                                                                        |
| **Output**           | Danh sách cảnh báo phù hợp với tiêu chí tìm kiếm                                                                                                                                                                         |
| **Basic Flow**       | 1. Người dùng chọn "Tìm kiếm"<br>2. Người dùng nhập/chọn tiêu chí tìm kiếm<br>3. Người dùng nhấn nút "Tìm kiếm"<br>4. Hệ thống tìm kiếm trong database<br>5. Hệ thống hiển thị danh sách kết quả<br>=> Kết thúc use case |
| **Alternative Flow** | **2a.** Người dùng chỉ nhập một số tiêu chí, các tiêu chí khác để trống<br>**3a.** Người dùng nhấn "Xóa bộ lọc" => Hiển thị lại tất cả cảnh báo => Kết thúc use case                                                     |
| **Exception Flow**   | **2a.** Người dùng thoát trang => Kết thúc use case<br>**5a.** Không tìm thấy kết quả => Hiển thị "Không tìm thấy cảnh báo phù hợp"                                                                                      |

| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| **Actors**           | Người dùng đã đăng nhập                                                                                                                                                                                                  |
| **Input**            | Chọn cảnh báo muốn xem                                                                                                                                                                                                   |
| **Output**           | Hiển thị thông tin chi tiết cảnh báo                                                                                                                                                                                     |
| **Basic Flow**       | 1. Người dùng chọn "Cảnh báo"<br>2. Người dùng chọn một cảnh báo từ danh sách<br>3. Hệ thống hiển thị thông tin chi tiết<br>4. Người dùng xem thông tin, vị trí, ảnh/video, người tạo, thời gian<br>=> Kết thúc use case |
| **Alternative Flow** | **1a.** Người dùng chọn "Xem bản đồ" => Hiển thị cảnh báo trên bản đồ<br>**1b.** Người dùng chọn "Xem danh sách" => Hiển thị danh sách cảnh báo                                                                          |

## 6. GỬI CẢNH BÁO (TẠO CẢNH BÁO MỚI)

| **Input**            | Loại cảnh báo, mức độ, đường, mô tả, ảnh/video (tùy chọn)                                                                                                                                                                                                                           |

Đang chờ duyệt"                                                                                                                                                                                                                                 |

Hệ thống lưu với trạng thái "chờ duyệt"<br>5. Hệ thống hiển thị "Gửi cảnh báo thành công"<br>=> Kết thúc use case                  |

| **Exception Flow**   | **2a.** Người dùng thoát trang => Không lưu => Kết thúc use case<br>**2b.** Không chọn đường => Hiển thị lỗi "Vui lòng chọn đường"<br>**2c.** Không nhập mô tả => Hiển thị lỗi "Vui lòng nhập mô tả"<br>**2d.** File upload quá lớn => Hiển thị lỗi "File không được vượt quá 10MB" |
